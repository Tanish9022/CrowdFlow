# Frontend Command Dashboard — Crowd Flow

## Overview
React 18 single-page application built on Vite featuring:
- Obsidian Command Center dark theme.
- Interactive vector-based Jigsaw Road Network map with SVG.
- Live CCTV video stream viewer with toggleable bounding box and trajectory overlays.
- What-If Disruption Simulator with Before vs. After comparative visualization.
- Advisory Signal Timing Plan review interface.
- Real-time WebSocket connection to the backend telemetry engine.

## Running Locally
```bash
cd frontend
npm install
npm run dev
```
Accessible at `http://localhost:5173`.
