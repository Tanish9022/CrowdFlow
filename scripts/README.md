# Utility Scripts — Crowd Flow

## Overview
This directory contains administrative and development utility scripts:
1. `generate_mock_video.py`: Generates synthetic traffic video clips for reproducible testing without real cameras.
2. `seed_network_db.py`: Populates the database with the default Pune urban road graph model.
3. `benchmark_cpu_inference.py`: Benchmarks YOLO detection latency across different CPU configurations.
